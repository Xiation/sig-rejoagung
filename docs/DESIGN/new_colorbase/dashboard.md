The color design system for Web GIS Rejoagung is built on an 80/20 "Semantic Breathing" logic. It prioritizes high-density data legibility by using breathable neutral surfaces (80%) and reserves the localized "Hijau Rejoagung" emerald accent (20%) for branding and active interactions.
1. The Core Brand: "Hijau Rejoagung"

    Primary (#059669 / Emerald-600): This is the functional anchor. It represents growth and agriculture. It is used for active sidebar states, primary action buttons, and dominant data points in charts.
    Primary Container (#ECFDF5 / Emerald-50): A soft tint used for "Success" states and subtle background highlights to reinforce the brand without overwhelming the user.

2. The Neutral Foundation (M3 Surface Tokens)

To prevent eye strain during prolonged spatial analysis, the system uses a cool neutral palette:

    App Canvas (#F8FAFC / Slate-50): The base background. It provides a crisp, off-white foundation that makes white content cards "pop."
    Surface / Cards (#FFFFFF): Pure white is used for the primary data containers to ensure maximum contrast for metrics and charts.
    Borders (#E2E8F0 / Slate-200): Used for "barely-there" structural dividers, maintaining organization without the clutter of heavy lines.

3. Typography & Hierarchy

    Primary Text (#0F172A / Slate-900): A deep navy-slate used for headings and big numbers. It is softer than pure black, reducing visual fatigue while maintaining "AA" accessibility.
    Secondary Labels (#64748B / Slate-500): Used for metadata, legends, and micro-copy to guide the eye toward the primary data.

4. Functional Semantic Alerts

Color is used as a data indicator for quick decision-making:

    Threat/Error (#FEF2F2 / Rose-50): Used for critical alerts like "Low Irrigation" or "Threat Matrix" items.
    Warning (#FFFBEB / Amber-50): Used for transient states like "In Progress" or "Masa Tanam" (Planting Season).
    Success (#ECFDF5 / Emerald-50): Used for optimal conditions, indicating "All Systems Go."

5. Multi-Categorical Chart Palette

For high-density charts, the system extends beyond emerald to provide categorical distinction:

    Agricultural: Emerald Tones.
    Livestock/Energy: Slate & Cool Blues.
    Zoning/Education: Warm Terracotta & Amber.
